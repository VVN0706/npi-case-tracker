# NPI 案件追蹤

追蹤部門工程師負責案件的進度，並彙整成狀態 Dashboard。

## 執行

```
pip install -r requirements.txt
python app.py
```

啟動後開啟 http://127.0.0.1:8090

第一次啟動會自動建立資料庫（`case_tracker.db`，已在 .gitignore 中排除）與預設管理員帳號：

- 帳號：`admin`
- 密碼：`admin123`

登入後請立即到「使用者管理」新增工程師帳號，並修改管理員密碼。

## 功能

- 案件會經過八個固定階段（開案 Kick-off → ... → PNR / 量產轉移），每個階段各自有一個狀態：未開始/進行中/延遲/卡關/完成/NA
- 總覽 Dashboard：各階段案件數、已全部完成數、逾期案件、卡關/延遲中案件、各工程師負載、最近更新
- 案件列表：可依工程師 / 目前階段 / 部門篩選
- 新增 / 編輯 / 刪除案件（只有負責工程師本人或管理員可修改）
- 工程師有部門（2620/2640/2650），案件的部門自動跟著負責工程師走
- 管理員：新增使用者帳號與部門、自訂階段名稱/顏色/完成判定基準
